## Added by hand afterwards

**Memory.** From Azure Monitor (`az monitor metrics list --metric WorkingSetBytes --interval
PT1M --aggregation Maximum`), the replica's working set was 273 MB in the minutes before the
batch, at most 1,155 MB in any minute of it, and 842 MB in the minutes after. Azure samples
the working set, so a peak of a few seconds can fall between samples.

**The false pass.** The one miss was a row of the sample whose heading isn't bold, at the bold
check's first setting (Check this when the heading measures less than 1.1 times as heavy as
the text). The drawn picture measures 1.09 times, but grainy, compressed copies like these
measure 1.096 to 1.101, so a copy Claude called bold could measure "heavier" and pass. The
setting is now 1.15 times; see docs/EVALUATION.md.
